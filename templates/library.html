Library Tools

Housekeeping for your local music library — separate from matching and building crates. This is the first part of crate-builder that can change your actual music files (not just read them), so every tag edit backs up the original first.

Used by the Metadata Editor's search, below.
Used by Duplicate Finder and Year Check — the folder containing "database V2".

Duplicate tracks

Reads Serato's own database directly — exactly what Serato itself sees, no library folder needed for this part. Groups tracks that look like the same song: exact matches after normalizing case/punctuation, plus close variants (like a missing featured-artist credit) that share the same title.

To clean up, tick the groups you want to fix and pick the copy to keep in each (the best guess is preselected: a file that exists, in the most crates, biggest file). The other copies are removed from Serato's library, and every crate that had them gets the kept copy instead, so no crate loses a song. Before anything is written, your Serato database and crates are backed up, and you can undo any cleanup below. Files are never deleted: they're moved to a "Crate Builder Removed Duplicates" folder in your home folder for you to check and empty yourself. Quit Serato DJ first — it saves its library when it closes and would undo the cleanup.

Year check

Cross-checks each track's tagged year against MusicBrainz. This is a review tool, not an auto-corrector — nothing gets written back automatically. Flagged tracks that don't match get a button to jump straight into the Metadata Editor above to fix the year by hand (with the usual automatic backup). Already-checked tracks are skipped on future runs, so stopping partway through and running again later — even after restarting the app — picks up where you left off instead of starting over.

Metadata editor

Search your library, pick a track, and edit its tags. The original file is backed up before every save — see "Recent backups" below to restore one if an edit goes wrong.
