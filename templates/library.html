Library Tools

Housekeeping for your local music library — separate from matching and building crates. This is the first part of crate-builder that can change your actual music files (not just read them), so every tag edit backs up the original first.

Duplicate tracks

Groups tracks that look like the same song — exact matches after normalizing case/punctuation, plus close variants (like a missing featured-artist credit) that share the same title. This only finds duplicates; nothing gets deleted automatically — review each group and remove files yourself in Finder/Explorer using the paths shown.

Metadata editor

Search your library, pick a track, and edit its tags. The original file is backed up before every save — see "Recent backups" below to restore one if an edit goes wrong.
